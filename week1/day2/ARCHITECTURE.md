# Architecture – CSS Flexbox & Grid

## Project Overview
This project demonstrates a responsive webpage using HTML5 and CSS3.

## Page Structure
- Header: Website name and navigation links.
- Main: Project heading and three project cards.
- Footer: Copyright information.

## Layout Design
- Flexbox: Used for navigation bar alignment.
- CSS Grid: Used for the three-column card layout.
- Media Queries: Used for mobile responsiveness.

## Data Flow
Not applicable. This is a static frontend webpage without backend APIs or database integration.
