# 💰 SpendWise – Smart Expense Tracker

A modern, responsive personal finance management web application built using HTML, CSS, and JavaScript. SpendWise helps users manage their income, track expenses, analyze spending habits, and maintain their financial records.

## ✨ Features

- **Dashboard:** View total balance, income, and expenses.
- **Add Transactions:** Record income and expenses.
- **Category Management:** Organize transactions by categories.
- **Expense Analytics:** Visualize category-wise spending.
- **Search Transactions:** Quickly find transactions.
- **Filter Transactions:** Filter income and expenses.
- **Delete Transactions:** Remove unwanted records.
- **CSV Export:** Download transaction history.
- **LocalStorage:** Save transaction data in the browser.
- **Responsive Design:** Works on desktop, tablet, and mobile devices.

## 🛠️ Technologies Used

- HTML5 – Website structure
- CSS3 – Styling and responsive design
- JavaScript ES6+ – Dynamic functionality
- LocalStorage API – Browser data persistence
- Blob API – CSV file export

## ⚙️ Installation and Setup

1. Clone this repository:

   ```bash
   git clone YOUR_GITHUB_REPOSITORY_URL
   ```

2. Open the project folder in VS Code.

3. Install the Live Server extension.

4. Right-click `index.html`.

5. Select Open with Live Server.

6. Start managing your income and expenses.
