
# PHP Fundamentals - Week 3 Day 1

## Project Overview
This project demonstrates the fundamental concepts
of PHP server-side programming.

## Technologies Used
- PHP 8.5
- HTML
- VS Code

## Topics Covered
1. PHP Variables and Data Types
2. Indexed and Associative Arrays
3. For, While and Foreach Loops
4. Conditional Statements
5. HTML Form Handling
6. Server-side Input Validation
7. GET and POST Methods
8. PHP Sessions
9. Input Sanitisation and XSS Prevention

## How to Run

1. Install PHP.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Execute:

   php -S localhost:8000 -t php_basics

5. Open http://localhost:8000/variables.php
